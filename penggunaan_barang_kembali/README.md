# Penggunaan Barang Kembali — Versi Gratis/Sukarela

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Buka `index.html` di browser atau gunakan ekstensi Live Server.

## Fitur prototype
- Login demo
- Beranda dan pencarian barang
- Bagikan/unggah barang
- Donasi barang
- Tukar barang
- Detail barang
- Chat
- Profil
- Favorit
- Riwayat aktivitas

## Catatan
Aplikasi tidak menggunakan harga dan tidak memiliki fitur jual beli.
Login, upload, chat, dan aktivitas masih simulasi frontend; belum terhubung ke database/backend.

fungsi setiap file
koneksi.php = berfungsi untuk menghubungkan php dengan database
